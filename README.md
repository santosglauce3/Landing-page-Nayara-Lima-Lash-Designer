# Landing Page - Nayara Lima Lash Designer

Projeto desenvolvido utilizando HTML e CSS para uma cliente da área de beleza.

## Tecnologias
- HTML5
- CSS3

## Funcionalidades
- Página responsiva
- Seção Sobre
- Serviços
- Galeria
- Botão para WhatsApp
- Redes sociais

## Objetivo
Praticar desenvolvimento front-end criando uma Landing Page personalizada de acordo com a identidade visual da cliente.
